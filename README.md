# DressMeApp Landing Page

A responsive, mobile-first landing page for DressMeApp - an AI-powered virtual try-on platform.

## Features

- Modern, responsive design
- Mobile-first approach
- Semantic HTML5
- CSS3 with BEM methodology
- Vanilla JavaScript (ES6+)
- Scroll animations
- Interactive FAQ accordion
- Form validation
- No dependencies

## Project Structure

```
DressMeApp/
│
├── assets/
│   ├── icons/         # SVG icons for benefits section
│   └── app-snippets/  # App screenshots and mockups
│
├── css/
│   └── style.css      # Main CSS file with BEM naming
│
├── js/
│   └── main.js        # JavaScript functionality
│
├── index.html         # Main HTML file
└── README.md          # Project documentation
```

## Getting Started

1. Clone this repository
2. Open `index.html` in your browser to view the landing page

Alternatively, you can use a local development server:

```bash
# Using Python:
python -m http.server

# Or with Node.js and npx:
npx serve
```

## Deployment

This is a static website that can be deployed on any static hosting platform such as:

- GitHub Pages
- Netlify
- Vercel
- Amazon S3
- Firebase Hosting

## Customization

### Colors and Variables

The site uses CSS variables for easy customization. Main variables are defined at the top of the `css/style.css` file.

### Images

1. Replace the placeholder images in the `assets/app-snippets/` directory
2. Replace SVG icons in the `assets/icons/` directory
